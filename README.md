# Counter Application

A simple and interactive counter application built with **HTML**, **CSS**, and **JavaScript**. The application allows users to increase, decrease, and reset a counter value without refreshing the page.

## Overview

This project demonstrates fundamental front-end web development concepts, including:

* DOM manipulation
* Event handling
* State management using JavaScript variables
* Dynamic content updates without page refresh
* Responsive user interface design

The counter value updates instantly whenever a user interacts with the control buttons.

---

## Features

| Feature           | Description                           |
| ----------------- | ------------------------------------- |
| Increment Counter | Increases the counter value by 1      |
| Decrement Counter | Decreases the counter value by 1      |
| Reset Counter     | Resets the counter value to 0         |
| Dynamic Updates   | Updates the displayed value instantly |
| Responsive Layout | Adapts to different screen sizes      |

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Aghaulor-Gift/simple-counter-app.git
```

2. Navigate to the project directory:

```bash
cd simple-counter-app
```

3. Open the project:

```bash
open index.html
```

Or simply double-click the `index.html` file in your file explorer.

---

## Usage

| Action        | Result                       |
| ------------- | ---------------------------- |
| Click "+"     | Increases counter value by 1 |
| Click "-"     | Decreases counter value by 1 |
| Click "Reset" | Resets counter value to 0    |

The displayed value updates immediately without reloading the page.
